# Clean Stream v0.20.0

Clean Stream finds live and upcoming events from sports schedules and aggregator catalogs, discovers aggregator sources, and plays compatible streams directly on the viewer or TV.

- Live-event search and pasted event links.
- Custom aggregator sources with category learning, import/export, selection, bulk deletion, and undo.
- Stream-only refresh, jump to live, AirPlay and Cast, and event metadata.
- Extraction browser recovery after failed startup or disconnection, delayed iframe discovery, and detailed server error logging.

Movies, shows, YouTube, and Twitch integrations have been removed. Legacy live-source profiles remain compatible. Streaming video is not relayed through Cloud Run. Source restrictions can still prevent direct playback, and hosting free-tier limits do not guarantee zero charges.
